# ليلة التحدي — Party Night V2

Mobile-first Arabic party hub designed for a single shared phone (2–10 players). No account required.

## Current games
1. تحدّي 30 — content packs, difficulty, direct/clue/list rounds, team scoring.
2. مين اللاعب؟ — football packs and difficulty.
3. الجواب المزوّر — secret pass-the-phone answers + private voting.
4. نفس التفكير — secret answers + match scoring.
5. على المقياس — clue spectrum + proximity scoring.
6. احكيها بدونها — team timed taboo-style rounds.
7. ارسم ومرّر — draw/guess chains with canvas undo.
8. وعاء الكلمات — three-round describe/one-word/charades loop.
9. القنبلة — hidden random timer + pass-the-phone category pressure.

## Platform systems
- Shared player list and session stats
- Persistent scores and session summary
- No-repeat content tracking per night
- PWA/offline cache
- Optional sound, haptics, screen wake lock
- Mobile-first RTL UI
- 700+ prompts/cards/words across the current content library
