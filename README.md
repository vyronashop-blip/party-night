# ليلة التحدي — Party Night V2.2

Mobile-first Arabic party hub designed for a single shared phone (2–10 players). No account required. Built as a PWA and designed to keep the real interaction between the people in the room, while the phone handles secrets, timers, scoring, drawing, voting and session flow.

## Current games — 16
1. تحدّي 30 — content packs, difficulty, seven round types, balanced question distribution, team scoring.
2. مين اللاعب؟ — football packs, difficulty and optional timer.
3. الجواب المزوّر — secret pass-the-phone answers + private voting.
4. نفس التفكير — secret answers + match scoring.
5. على المقياس — clue spectrum + proximity scoring.
6. احكيها بدونها — team timed forbidden-word rounds.
7. ارسم ومرّر — draw/guess chains with canvas undo.
8. وعاء الكلمات — three-round describe / one-word / charades loop.
9. القنبلة — hidden random timer + pass-the-phone category pressure.
10. خمس ثواني — name three things before the timer ends.
11. اختيار الأغلبية — secret A/B voting and majority scoring.
12. رتّبها — order facts, events and football moments correctly.
13. فك الشفرة — emoji decoding across football, movies and general topics.
14. أقرب رقم — private numeric guesses; closest answer wins.
15. لمحة — short-term memory challenge with decoy choices.
16. همسة — pass a phrase around the room and compare the final result.

## Platform systems
- Smart Party Builder: generates a varied playlist based on session duration, vibe and player count
- Party presets: football, experts, family, quick, chaos and Barça-inspired nights
- Championship mode across multiple mini-games
- Shared player list, scoring, session stats and night awards
- Lifetime achievements and local play history
- Favorites, game search and recent-games shortcuts
- Player emoji avatars stored locally
- No-repeat content tracking per night
- PWA/offline cache
- Optional sound, haptics and screen wake lock
- Accessibility/comfort controls: larger text, reduced motion, higher contrast and extended timers
- Web Share support for quickly inviting friends
- Mobile-first RTL UI with a deep blue / red / gold football-inspired visual identity
- Large expandable content library with curated football difficulty tiers

## UX principles
- One phone can run the entire night
- Secret information is passed player-to-player
- Large touch targets and low setup friction
- Built-in rules for every game
- Fast return to the home hub and session tools
- Offline-first after the first successful load
